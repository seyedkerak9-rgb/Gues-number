
# 🎯 Number Guessing Game

A simple and fun number guessing game built with HTML, CSS, and JavaScript.

## 🎮 About the Game

The computer randomly chooses a number between 1 and 100. Your goal is to guess the correct number!

After each guess, the game tells you whether you should choose a bigger or smaller number.

## ✨ Features

- Random number generation (1–100)
- Check user's guesses
- Helpful hints (bigger or smaller)
- Count the number of attempts
- Winning message
- Success image when you win
- Disable the guess button after winning

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start guessing!

## 🕹️ How to Play

1. Enter a number between 1 and 100.
2. Click the Guess button.
3. Follow the hints to find the correct number.
4. Try to win with fewer attempts!
